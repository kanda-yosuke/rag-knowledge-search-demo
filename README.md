# RAG Knowledge Search Demo

A lightweight **Retrieval-Augmented Generation (RAG) style knowledge search demo** built with Python and Streamlit.

This project demonstrates how structured documents can be indexed and searched to quickly retrieve relevant knowledge.

It is designed as a **minimal prototype of a knowledge search system**, which can later be extended with embeddings and vector search.

---

# Demo

This repository includes a sample dataset and a Streamlit UI to demonstrate knowledge search functionality.

Demo data and detailed instructions are available here:

demo/README.md

---

# Features

- Keyword-based document search
- Metadata filtering (category, tags, etc.)
- Highlighted search matches
- Jump navigation to relevant sections
- Lightweight Streamlit UI
